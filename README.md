# Dalal Enterprises Murbad – Static Website

Professional multipage static website for **दलाल इंटरप्राईजेस, मुरबाड** (CSC / Maha e-Seva / Xerox & Online Services).

## Stack
- HTML5, CSS3, Bootstrap 5, JavaScript
- Bootstrap Icons
- Google Fonts: Noto Sans Devanagari + Poppins

## Pages
- `index.html` – Home
- `services.html` – Full services listing
- `gallery.html` – Photo gallery + lightbox
- `about.html` – About business
- `contact.html` – Offices, maps, WhatsApp enquiry form
- `privacy-policy.html`
- `terms-and-conditions.html`
- `refund-policy.html`
- `404.html`

## Run locally
1. Open `index.html` in a browser, **or**
2. Use VS Code Live Server / any static host.

## Deploy (GoDaddy / any static host)
1. Upload all files preserving folder structure.
2. Replace `https://YOUR-DOMAIN.com` in:
   - canonical tags
   - Open Graph / JSON-LD (home)
   - `sitemap.xml`
   - `robots.txt`
3. Point domain document root to this folder.
